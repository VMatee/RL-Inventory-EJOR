# M5 Forecasting — Accuracy, Walmart (primary real-data track)

**Verified local acquisition:** 2026-10-17. All 5 raw CSVs in `data/raw/m5/` passed exact published Zenodo record filesize and MD5 checks; full SHA256 recorded in `data/manifests/m5_verified_20261017.json`.

- Original competition: https://www.kaggle.com/competitions/m5-forecasting-accuracy/data
- Public source and metadata mirror supplied by original M5 organizer, University of Nicosia: https://zenodo.org/records/10203108 , DOI https://doi.org/10.5281/zenodo.10203108
- Organizer's methods and benchmark artifacts: https://github.com/Mcompetitions/M5-methods
- Pinned *transport mirror* for larger identical CSVs: https://huggingface.co/datasets/kashif/M5/tree/849da4b68665cb20e6a904f7a5e2581093589483 ; integrity independently cross-checked against Zenodo. Do not treat mirror contents as a new dataset.

| File | Bytes | Role |
|---|---:|---|
| `calendar.csv` | 103469 | Dates, events, SNAP flags |

Acquisition in this project used Zenodo for the two small files and pinned Hugging Face file-revision range requests for the other three, then validated **all five byte identities against Zenodo MD5** before accepting any raw CSV. The old timed-out partial from a direct Zenodo request was removed only once the complete file passed verification.
